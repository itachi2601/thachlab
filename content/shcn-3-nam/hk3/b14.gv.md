# Đánh giá đóng góp và tự đánh giá — kịch bản giảng viên

## Thông tin nhanh

| | |
|---|---|
| Mục tiêu | Mỗi SV điền đủ phiếu đánh giá đóng góp cho mọi thành viên nhóm dự án (kể cả mình) dựa trên việc đã làm; mỗi SV bắt đầu lịch ôn thi. |
| Ghi biên bản | Chủ đề 6: Kỹ năng làm việc nhóm · Phương pháp đánh giá hoạt động của nhóm |
| Chuẩn bị | In 80 phiếu đánh giá (hoặc Google Form chỉ GVCN xem kết quả); 8 phong bì có ghi số nhóm; chiếu mẫu lịch ôn thi. |
| Ai dẫn | GVCN: Mở, Cốt lõi, Chốt. **Nhóm dẫn 14**: phần Làm 10' (phát, giải thích, thu phiếu). |
| Nhóm dẫn chuẩn bị (giao sau bài 13) | In/ tạo Form; ghi sẵn tên thành viên từng nhóm vào phiếu (lấy từ biên bản họp 1); xếp chỗ để SV điền **riêng, không nhìn phiếu nhau** (ngồi giãn, quay mặt ra); thu phiếu vào phong bì dán kín, giao tận tay GVCN. Nhóm dẫn **không đọc** phiếu. |

## Đầu tiết (trong 5' ổn định)

Hỏi lại bài 13:

> "Thư ký các nhóm đã gửi sản phẩm cuối và biên bản chưa? … Tuần trước nhóm em học được điều gì từ phần báo
> cáo của nhóm khác? Một bạn nói."

GV công bố bảng điểm dự án đã tổng hợp (theo nhóm, không xếp hạng 1–8).

## Kịch bản 20'

**Mở (2')** — Kể chuyện Lan (bản SV), hỏi:

> "Nếu em là Lan, em cho cả nhóm điểm như nhau không? Giơ tay: có… không…"

Thường chia đôi. GV:

> "Cho như nhau thì dễ chịu hôm nay. Nhưng người làm nhiều sẽ thôi làm nhiều, người làm ít không biết cần
> sửa."

**Cốt lõi (5')**

1. *Đánh giá việc đã làm, không đánh giá tính cách.*
   > "Mở biên bản ra. Ai nhận gì, xong chưa, đúng hạn không. Đó là bằng chứng."
2. *Tự đánh giá thật là kỹ năng nghề.*
   > "Đi làm, cuối năm các em tự báo cáo công việc. Tập ngay từ bây giờ. Thầy/cô so tự đánh giá với đánh giá
   > của cả nhóm — chênh lệch nhiều sẽ hỏi riêng."
3. *Đánh giá để lần sau tốt hơn.*
   > "Phiếu chỉ thầy/cô đọc. Không ai trong lớp biết em chấm ai bao nhiêu. Góp ý viết theo mẫu bài 8."

**Làm (10') — nhóm dẫn 14 điều phối**

Phút 0–1: nhóm dẫn phát phiếu, giải thích 3 phần, nhắc "chia 100 điểm cho cả nhóm, tổng phải đúng 100".
Phút 1–8: SV điền riêng, im lặng. Ai cần xem lại biên bản thì mở nhóm Zalo trên điện thoại.
Phút 8–10: nhóm dẫn thu phiếu theo nhóm, cho vào phong bì, dán kín, giao GVCN.

Câu hay gặp:
- *"Em không nhớ ai làm gì"* → "Mở biên bản và tin nhắn nhóm. Không có bằng chứng thì chia đều phần đó và ghi
  'không rõ' — thầy/cô sẽ hỏi trưởng nhóm."
- *"Em ngại ghi bạn làm ít"* → "Ghi việc, không ghi tính cách: 'nhận 2 việc, xong 0'. Đó là sự thật, không
  phải xúc phạm."

**Chốt + việc tuần (3')** — chuyển sang ôn thi:

> "Dự án xong. Giờ là mùa thi. Việc tuần: lập lịch ôn — đếm ngược 14 ngày từ ngày thi, môn khó ôn trước và
> ôn hai vòng, tự làm đề trước khi đọc lại, và giữ giờ ngủ. Câu nếu–thì: 'Nếu tôi ngồi vào bàn học buổi tối,
> thì tôi làm đúng một dòng của lịch ôn trước khi mở điện thoại.'"

Giao bản GV tiết Tổng kết cho nhóm dẫn 15 và 16.

## Phiếu hoạt động

**PHIẾU ĐÁNH GIÁ ĐÓNG GÓP — DỰ ÁN NHÓM PHỤC VỤ LỚP** (chỉ GVCN xem)

Họ tên người đánh giá: ………………… Nhóm dự án số: ……

**Phần 1 — Chấm từng người (kể cả mình), mỗi ô 1–4**
1 = hầu như không · 2 = dưới mức đã nhận · 3 = làm đủ việc đã nhận · 4 = làm đủ và vượt (giúp người khác,
làm thêm phần khó)

| Thành viên | Xong việc đúng hạn | Chất lượng phần việc | Có mặt, tham gia họp | Hỗ trợ người khác | Giao tiếp, thái độ | Chia 100 điểm |
|---|---|---|---|---|---|---|
| (Tôi) | | | | | | |
| | | | | | | |
| | | | | | | |
| | | | | | | |
| | | | | | | |
| | | | | | | |
| | | | | | | |
| | | | | | | |
| | | | | | | |
| | | | | | | |
| | | | | | | **Tổng = 100** |

Cột "Chia 100 điểm": chia 100 điểm cho cả nhóm theo phần đóng góp thật (nhóm 10 người, đóng góp đều thì mỗi
người 10).

**Phần 2 — Tự đánh giá**

- Những việc tôi đã nhận và kết quả: ………………………
- Điều tôi làm tốt nhất trong dự án: ………………………
- Một điều tôi sẽ đổi ở cách làm của mình lần sau: ………………………

**Phần 3 — Góp ý** (theo mẫu điều tốt – điều nên sửa – gợi ý; ít nhất cho 1 người)

- Gửi bạn …………: ………………………
- Người tôi muốn cảm ơn nhất và vì sao: ………………………

## Đáp án / gợi ý chốt

Cách GVCN đọc phiếu (sau tiết, khoảng 10 phút/nhóm):

- Tính trung bình cột "Chia 100 điểm" mỗi người từ các phiếu **khác** phiếu của chính họ.
- Đánh dấu: người nhận dưới khoảng một nửa mức đều (nhóm 10 người: dưới 5) ở đa số phiếu → gặp riêng, hỏi lý do
  trước khi kết luận (đi làm, ốm, chuyện gia đình…).
- Tự đánh giá cao hơn trung bình nhóm nhiều → gặp riêng, cho xem biên bản, không đọc phiếu của ai.
- Người được nhiều phiếu "cảm ơn nhất" → khen trước lớp ở tiết Tổng kết (khen việc cụ thể).

## Lưu ý

- Giữ bí mật phiếu tuyệt đối: không chụp phiếu gửi nhóm, không nêu "bạn X chấm bạn Y".
- SV đóng góp ít vì hoàn cảnh (làm thêm, ốm, gia đình): nói chuyện riêng, ghi nhận lý do; không phạt trước lớp.
- Nếu kết quả dùng cho điểm rèn luyện: **[GV kiểm tra trước khi dạy: quy định chấm điểm rèn luyện của trường có
  cho dùng đánh giá đồng đẳng không.]**
- Thiếu thời gian: SV điền Phần 1 và 2 trên lớp, Phần 3 điền Form trước tối Chủ nhật.
