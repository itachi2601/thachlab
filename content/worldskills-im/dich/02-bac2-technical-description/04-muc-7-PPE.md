# TD mục 7: Yêu cầu an toàn riêng của nghề — Trang bị bảo hộ cá nhân (PPE)

> Nguồn: WSC2026_TD01_en, mục 7.1, tr. 23–24. **Bảng dựng lại từ PDF gốc** (đã đối chiếu từng ô bằng hình trang 23–24) vì bản text trích bị vỡ cột. Bậc 2 — dành cho giáo viên huấn luyện.

## Ý nghĩa cho huấn luyện

- **Thí sinh tự mang PPE** (TD 8.4); Expert và phiên dịch cũng tự mang (8.5–8.6, xem file 05). Trường chuẩn bị đủ bộ khi thi thử.
- **Kính bảo hộ có chắn bên hông, giày bảo hộ mũi thép (có mũi bảo vệ) và quần áo bó sát, quần dài** bắt buộc ở **cả 5 loại công việc**, kể cả khu vực an toàn thông thường.
- **Mũ/lưới trùm tóc và bảo vệ thính giác** bắt buộc khi hàn–chế tạo, gia công, nâng hạ, dụng cụ cầm tay — chỉ *khu vực an toàn chung* là không yêu cầu.
- **Hàn–chế tạo là loại đòi hỏi PPE nhiều nhất**: mặt nạ hàn + găng hàn + găng chống cắt (khi không hàn) + quần áo chống cháy, cùng toàn bộ PPE chung.
- **Nâng hạ thiết bị**: thêm găng chống cắt, không cần găng hàn.
- Cột "giày chắc chắn, kín mũi, không gót" (Sturdy shoes) **không có dấu ✓ ở hàng nào** (xem Ghi chú bản gốc #2); loại giày bắt buộc ở mọi hàng là *giày bảo hộ có mũi bảo vệ*.

## Bảng PPE theo loại công việc

Chú giải: ✓ = bắt buộc theo TD (ô trống = TD không yêu cầu).

| Loại công việc / Task | Kính bảo hộ có chắn bên hông (Safety glasses with side protection) | Mặt nạ hàn (Welding mask) | Găng hàn (Welding gloves) | Găng chống cắt (Cut protection gloves) | Giày bảo hộ có mũi bảo vệ (Safety shoes with protective cap) | Giày chắc chắn, kín mũi, không gót (Sturdy shoes with closed toe and no heel) | Quần áo bó sát, quần dài (Tight fitting work clothes – long trousers/pants) | Quần áo chống cháy (Fire resistant protective clothes) | Lưới/mũ trùm tóc (Hairnet/hat) | Bảo vệ thính giác (Hearing protection) |
|---|---|---|---|---|---|---|---|---|---|---|
| Khu vực an toàn chung (General PPE for safe areas) | ✓ | | | | ✓ | | ✓ | | | |
| Hàn và chế tạo (Welding and Fabrication) | ✓ | ✓ | ✓ | ✓ *(khi không hàn / when not welding)* | ✓ | | ✓ | ✓ | ✓ | ✓ |
| Gia công — tiện/phay đứng (Machining – Lathe/Vertical Milling M/C) | ✓ | | | | ✓ | | ✓ | | ✓ | ✓ |
| Cẩu/nâng thiết bị (Rigging/Lifting of equipment) | ✓ | | | ✓ | ✓ | | ✓ | | ✓ | ✓ |
| Dụng cụ cầm tay, khoan tay, cưa lỗ… (Hand tools/hand drills/hole saws etc.) | ✓ | | | | ✓ | | ✓ | | ✓ | ✓ |

Cách dùng khi lập danh sách PPE cho từng module:

| Module | Công việc chính | PPE cần có (ngoài PPE chung: kính, giày bảo hộ, quần áo bó sát) |
|---|---|---|
| B (hàn, lấy dấu) | Hàn và chế tạo; dụng cụ cầm tay | + mặt nạ hàn, găng hàn, găng chống cắt (khi không hàn), quần áo chống cháy, lưới/mũ, bảo vệ tai |
| C (tiện, phay) | Gia công | + lưới/mũ trùm tóc, bảo vệ tai (không găng) |
| A, D, E, G (lắp ráp, bảo trì) | Dụng cụ cầm tay; nâng hạ khi cần | + lưới/mũ, bảo vệ tai; găng chống cắt khi nâng hạ |

[Ghi chú dịch: cột "Module → công việc" ở bảng thứ hai là gợi ý của người dịch để giáo viên dùng nhanh, **không phải nội dung TD**. TD chỉ phân theo 5 loại công việc ở bảng trên.]

## Ghi chú bản gốc

1. **Bản text trích (pdftotext) vỡ cột**: PPE ở mục 7.1 chia thành **bốn** bảng nhỏ theo cột (4 → 3 → 3 → 2 cột PPE) và ngắt trang giữa chừng (bảng thứ ba tách qua tr. 23–24). Bảng trên là gộp lại và đã đối chiếu từng ô với PDF gốc.
2. **Cột "Sturdy shoes with closed toe and no heel" trống hoàn toàn** ở cả 5 hàng. Có thể là cột thừa còn sót từ bản TD cũ, hoặc nghĩa là loại giày này không phải PPE bắt buộc khi đã có giày mũi thép. Dịch nguyên, không suy đoán.
3. **Hàng "General PPE for safe areas" không có ✓ ở "Hairnet/hat" và "Hearing protection"** — đúng theo bản gốc; hai ô này trống.
4. TD ghi dấu "√" (căn bậc hai) thay cho "✓"; chuyển sang ✓ cho dễ đọc, ý nghĩa như nhau.
5. **"Cut protection gloves" ở hàng Welding and Fabrication** có điều kiện "(When not welding)" — găng chống cắt dùng khi không hàn (khi hàn dùng găng hàn).
